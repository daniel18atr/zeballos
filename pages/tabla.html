Glosario

Feedback Retroalimentación o comentarios que se dan sobre un producto o trabajo, para mejorarlo o ajustar su funcionamiento.
Software Conjunto de programas, aplicaciones y sistemas que hacen funcionar una computadora o dispositivo electrónico.
Hardware Componentes físicos de un sistema informático, como el monitor, el teclado, el disco duro o el procesador.
Bugs Errores o fallos en un programa que provocan comportamientos inesperados o incorrectos.
Stakeholders Personas o grupos interesados o afectados por un proyecto (clientes, usuarios, desarrolladores, empresa, etc.).
Algoritmo Conjunto de pasos lógicos y ordenados que permiten resolver un problema o realizar una tarea específica.
Interfaz Punto de interacción entre el usuario y el sistema. Puede ser visual (pantallas, botones) o técnica (entre programas).
Base de datos Conjunto organizado de información que puede almacenarse, consultarse y actualizarse fácilmente.
Iteración Proceso de identificar y corregir errores (bugs) en un programa informático.
Repositorio Espacio donde se almacena el código fuente de un proyecto, generalmente en línea (por ejemplo, GitHub).
Prototipo Versión inicial o de prueba de un producto, usada para validar ideas o funciones antes del desarrollo completo.
Usabilidad Facilidad con la que los usuarios pueden aprender y utilizar un sistema de manera efectiva y satisfactoria.
Mantenimiento Conjunto de actividades destinadas a corregir errores, mejorar o adaptar un software después de su lanzamiento.
Escalabilidad Capacidad de un sistema o aplicación para aumentar su rendimiento o tamaño sin perder eficiencia.
